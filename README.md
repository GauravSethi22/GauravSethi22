## 🚀 Signature Projects

### 🛡️ [FinGuard](https://github.com/GauravSethi22/finguard) — Real-Time Fraud Detection Pipeline
- End-to-end fraud detection pipeline using **Apache Kafka (Confluent Cloud)**, **PySpark**, and **Databricks Lakeflow**
- Processes live credit card transactions through a **Bronze–Silver–Gold Medallion Architecture**
- Streaming ETL with **Lakeflow Declarative Pipelines**, stream-static joins with PostgreSQL customer data, rule-based fraud detection, and real-time alerting with email notifications

---

### 🤖 [Talk_to_Data](https://github.com/GauravSethi22/Talk_to_Data_updated) — Multi-Agent Natural Language-to-SQL Pipeline
- 6-layer NL-to-SQL pipeline built with **GroqAPI** and **Redis-based semantic caching** for low-latency query processing
- Multi-agent execution engine with **planner, coder, and validator agents** operating over a secure read-only database
- Built with Python, LangGraph, ChromaDB, PostgreSQL, and Streamlit

---

### 📟 [oncall-engineer-env](https://github.com/GauravSethi22/oncall-engineer-env)
- AI on-call engineer **reinforcement learning environment** for production incident response
- Built in Python to simulate and train agents on realistic on-call / incident-response scenarios

---

### 💊 [Medical-Chatbot-Generative-AI](https://github.com/GauravSethi22/Medical-Chatbot-Generative-AI)
